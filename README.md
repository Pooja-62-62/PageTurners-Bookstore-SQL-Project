# PageTurners Bookstore – Data Management using SQL Server

## 📖 Project Overview
This project is part of my MBA mini project where I solved real-world data management challenges faced by a local bookstore.

The bookstore struggled with:
- Tracking inventory
- Identifying best-selling books & authors
- Analyzing customer purchase patterns
- Generating revenue insights

## 🛠️ My Solution
Using SQL Server, I:
- Created a structured database (Books, Authors, Customers, Orders, OrderDetails)
- Cleaned the data (duplicates, NULL values)
- Wrote SQL queries to answer business questions like:
  - Top 3 best-selling books
  - Revenue earned per genre
  - Premium customers (high-value orders)
  - Average price of books per author
